# Project Context

## Purpose

Committed project context for Mindstream. Use this folder for durable technical knowledge such as architecture notes, ADRs, operating procedures, and decisions that should remain in version control.

## Current Direction

Mindstream is being rebuilt as a **React-first YouTube Channel Monitoring and Transcript Intelligence Platform**.

- The previous Streamlit/Python proof-of-concept is archived in [`POC/P_01/`](../../POC/P_01/).
- The new platform will feature React frontend, FastAPI backend, background worker, PostgreSQL, and vector search.
- All feature work must flow through the `space_framework` state machine before implementation begins.
